# Advanced Multi-Agent System

A sophisticated AI system featuring a Supervisor-led architecture with specialized agents for complex task execution.

## 🚀 Core Capabilities
- ❖ **Multi-step Reasoning**: Breaking down complex queries into logical, actionable steps.
- ❖ **Task Planning**: Dynamic generation of execution strategies.
- ❖ **Execution Logs**: Full transparency with detailed internal logs.
- ❖ **Smart Delegation**: A Main Supervisor Agent orchestrates specialized agents through a dedicated communication layer.
- ❖ **Filtering Agent**: Extracts important information for short, clear, and exact responses.

## 👥 Specialized Agents
- **Research Agent**: Gathers data and facts.
- **Coding Agent**: Writes and explains high-quality code.
- **Planning Agent**: Creates structured strategies and timelines.
- **Response Gen Agent**: Compiles final professional communications.
- **Filtering Agent**: Refines all outputs for maximum impact and clarity.

## 🏗️ Architecture
- **Backend**: FastAPI with `openai-agents` framework.
- **Frontend**: Next.js 15 with Tailwind CSS.
- **Database**: Neon PostgreSQL for persistent logging.
