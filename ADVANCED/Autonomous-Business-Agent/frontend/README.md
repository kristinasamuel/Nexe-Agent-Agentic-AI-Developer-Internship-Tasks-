# Autonomous Business Agent - Frontend

A professional, high-performance web interface for the Autonomous Business Agent.

## Features
- **Clean Chat Interface**: Modern UI for interacting with the AI Agent.
- **Autonomous Log Viewer**: Sidebar to browse past executions and internal reasoning steps.
- **Responsive Design**: Works perfectly on mobile and desktop.
- **Real-time Status**: Monitors the connection to the backend.

## Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **Styling**: Tailwind CSS 4
- **Language**: TypeScript
