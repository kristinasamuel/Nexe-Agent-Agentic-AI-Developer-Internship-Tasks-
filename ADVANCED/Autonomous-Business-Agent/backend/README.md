# Autonomous Business Agent - Backend

This is the backend for the Autonomous Business Agent, built with FastAPI and the OpenAI Agents framework. It features multi-step reasoning and automated task planning.

## Features
- **Multi-step Reasoning**: The agent is configured to think step-by-step and create structured plans.
- **Database Integration**: All interactions and internal execution logs are saved to a Neon PostgreSQL database.
- **Gemini AI**: Powered by Google's Gemini models via the OpenAI-compatible API.
